## 운영 철학 — 프로세스 기반 자유도 (Autonomy within Guardrails)

역할자에게 **방법(How)의 자유**는 최대한 부여한다. 단, **오케스트레이션 통제**는 모두가 따른다:
① 통제 7대 규칙 · ② RACI 책임 · ③ 핸드오프 산출물 계약 · ④ 표준(OWASP/CWE/CVSS) · ⑤ 에스컬레이션.
→ *자유는 통제라는 경계 안에서 결과물을 창출하기 위한 것.*

```
   ┌──────────────────── 통제 (경계) ────────────────────┐
   │  7대 안전장치 · RACI · 산출물 계약 · 표준 · 에스컬레이션      │
   │   ┌─────────────────────────────────────────┐      │
   │   │   자유도 (How: 기법·도구·설계·작업 순서)            │ ─▶ 결과물
   │   └─────────────────────────────────────────┘      │
   └──────────────────────────────────────────────────────┘
```

## 결정권 (누구 말이 최종인가)

| 사안 | 최종 결정 |
|------|-----------|
| 합법성·스코프 | **컴플라이언스** (veto = 스캔 중단권) |
| 오탐 여부 | **취약점 연구원** (재현 데모로 판정) |

## 핸드오프 체인 (요약 — 상세는 [../PLAN.md](../PLAN.md) §6)

```
S0 스코프정의(CMP/PM) ─▶ S1 자산인벤토리(BE) ─▶ S2·S3 점검(SEC) ─▶ S4 확정취약점(SEC/QA)

```
