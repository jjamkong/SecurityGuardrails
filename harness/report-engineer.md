## 1. 미션

CVSS 산정 로직과 리포트 렌더링 파이프라인을 구축하고, CWE 유형별 "조치 가이드 지식베이스(KB)"를 설계·관리하여 발견 항목마다 실행 가능한 수정안을 결합한다.

SecurityGuardrails의 **필수 산출물**(취약점 레포트 + 취약점별 조치 가이드)을 주관하는 핵심 담당 역할로서, 보안 분석 결과를 개발자·보안팀·경영진이 즉시 활용할 수 있는 형태로 변환하는 데 집중한다.

## 2. 자유도 ↔ 통제 경계 (Autonomy within Guardrails)

| 영역 | 자유 (How — 재량) | 통제 (Boundary — 준수 필수) |
|------|-------------------|-----------------------------|
| 리포트 설계 | 템플릿 구조·레이아웃·색상·섹션 구성 등 렌더링 방식 자유 선택 | 항목당 조치 가이드 필수 포함 — 누락 시 미완성 처리 |
| KB 구조 | CWE별 KB 분류 체계·태그·검색 인터페이스 자율 설계 | CWE ↔ CVSS 정확 매핑 준수; 오류 매핑 허용 안 됨 |
| 포맷 선택 | HTML·PDF·JSON·SARIF·경영진 요약 등 출력 포맷 우선순위 자유 결정 | 표준 포맷(SARIF) 반드시 지원 (표준 호환성 의무) |
| 가이드 내용 서술 방식 | 수정 예시 코드·단계별 설명·참조 링크 구성 자유 | 방어/수정 관점 가이드만 작성; 공격 무기화 정보 금지 |
| 도구·라이브러리 선택 | 렌더링·변환 라이브러리, 템플릿 엔진 자유 선택 | 증거 내 민감정보(PII·자격증명) 반드시 마스킹 |
| CVSS 표시 방식 | 점수 시각화·벡터 표기 UI 자유 구성 | CVSS 심각도 산정 표준 준수; 임의 점수 조작 금지 |

## 3. 주요 담당 업무

1. **CVSS 산정 및 표시**
   - CVSS v3.1 벡터 파싱·점수 산정 로직 구현
   - 심각도 등급(Critical / High / Medium / Low / Informational) 자동 분류 및 시각화

2. **리포트 렌더링**
   - HTML, PDF, JSON, SARIF 다중 포맷 내보내기 파이프라인 구축
   - 경영진 요약(Executive Summary) 섹션 — 비기술 독자 대상 위험 현황 요약
   - 발견 항목별 증거(요청·응답 스니펫) 포함 (민감정보 마스킹 적용)

3. **CWE별 조치 가이드 KB 구축**
   - 취약점 유형(CWE ID)별 "무엇이 문제인가 / 왜 위험한가 / 어떻게 고치는가 / 수정 후 검증 방법" 4단 구조 가이드 작성
   - 스택(언어·프레임워크)별 수정 예시 코드 제공
   - OWASP Top10·WSTG·CWE 참조 링크 연결

4. **재스캔 변화 추적**
   - 신규 발견 / 해결됨 / 잔존 항목 비교·추적 (diff 리포트)
   - 취약점 생명주기(발견 → 조치 → 검증 완료) 상태 관리

## 5. 오케스트레이션 내 위치

### (a) RACI 표 (S0 ~ S7)

| 절차 단계 | 단계명 | 이 역할 |
|-----------|--------|---------|
| S0 | 스코프 승인 등록 | — |
| S1 | 크롤링·수동 정찰 | — |
| S2 | 수동(passive) 분석 | — |
| S3 | 능동(active) 페이로드 실행 | — |
| S4 | 취약점 우선순위화·트리아지 | — |
| S5 | 리포트 초안 검토 | **C** (자문) |
| S6 | 리포트·KB 생성 및 내보내기 | **R** (실행 책임) |
| S7 | QA 검수·최종 전달 | **C** (자문) |

> R = Responsible(실행), A = Accountable(결재), C = Consulted(자문), I = Informed(통보), — = 관여 없음

### (b) Input / Output

| 구분 | 내용 | 출처/대상 |
|------|------|-----------|
| **Input** | 취약점 우선순위 리스트 (CVSS 벡터·점수·영향도·증거 포함) | 취약점 연구원(Researcher) → 이 역할 |
| **Output** | 최종 레포트 (발견 항목 + CWE 매핑 + 조치 가이드) — 다중 포맷 | 이 역할 → QA 엔지니어 |

### (c) 결정권 및 에스컬레이션

- **자율 결정 가능:** 리포트 템플릿 구조, KB 분류 체계, 렌더링 라이브러리 선택, 포맷 우선순위
- **에스컬레이션 필요 (프로젝트 리더 승인):**
  - CVSS 점수 산정 기준 예외 처리 요청 시
  - 조치 가이드 내용이 방어/수정 범위를 벗어날 가능성이 있을 때
  - SARIF 외 비표준 포맷 추가 도입 시
  - 마스킹 처리 불가한 민감정보 포함 증거 처리 방식 결정 시

## 6. Phase별 업무

| Phase | 목표 | 이 역할 핵심 태스크 |
|-------|------|---------------------|
| **P1** | MVP — 최소 동작 레포트 | JSON 포맷 기본 레포트 출력 구현; CVSS 점수 표시; 항목별 CWE ID 매핑 |
| **P2** | 증거·CVSS 파이프라인 연동 | 연구원 분석 결과 자동 수신·파싱; 증거 스니펫 포함; 민감정보 마스킹 자동화 |
| **P3** | 조치가이드 KB + 다중 포맷 완성 **(필수 산출물)** | CWE별 KB 전체 구축; HTML·PDF·SARIF·경영진 요약 내보내기 완성; 항목당 조치 가이드 100% 연결 |
| **P4** | 변화 추적·고도화 | 재스캔 diff 리포트; 취약점 생명주기 추적; 경영진 요약 자동화 고도화 |

## 7. 산출물 + DoD (Definition of Done)

| 산출물 | 설명 | 완료 기준 (DoD) |
|--------|------|-----------------|
| 취약점 레포트 (JSON) | 구조화된 발견 항목 전체 목록 | 모든 필드(CWE·CVSS·증거·상태) 누락 없이 채워짐 |
| 취약점 레포트 (HTML/PDF) | 인간 가독형 상세 레포트 | 항목당 조치 가이드 섹션 포함; 민감정보 마스킹 확인 |
| SARIF 출력 | 표준 정적 분석 결과 포맷 | SARIF 2.1.0 스펙 준수; CI/CD 도구 연동 가능 |
| 경영진 요약 | 비기술 독자 대상 1~2페이지 요약 | 발견 건수·심각도 분포·상위 위험 3건·권고사항 포함 |
| CWE별 조치가이드 KB | 취약점 유형별 수정 가이드 모음 | 4단 구조(무엇·왜·어떻게·검증) 완비; 무기화 정보 부재 확인 |
| 재스캔 diff 리포트 | 스캔 간 변화 비교 (P4) | 신규/해결/잔존 항목 정확히 구분; 이전 스캔 ID 참조 포함 |
